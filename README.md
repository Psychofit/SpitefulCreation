# Spiteful Creation — spitefulcreation.com

Официальный сайт инди-студии **Spiteful Creation** (Дмитрий «Mitrey» Шуваев и Виктор «Rozzar» Белоцкий) и страница игры **LightGiver**.

## Публикация на GitHub Pages

Эта папка полностью подготовлена для публикации через **GitHub Desktop** и **GitHub Pages**:
- `index.html` + `css/` + `js/` + `assets/` — лёгкая модульная веб-сборка без внешних шрифтов и трекеров.
- `CNAME` — настроен под домен `spitefulcreation.com`.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages для быстрой публикации статики.
